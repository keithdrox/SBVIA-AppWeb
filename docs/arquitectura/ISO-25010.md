# Atributos de Calidad (ISO/IEC 25010)

Esta tabla resume los atributos de calidad seleccionados para el sistema SBVIA, de acuerdo a la norma ISO/IEC 25010.

| Atributo (Característica) | Sub-característica | Prioridad | Escenario de Calidad | Estrategia Arquitectónica |
|---------------------------|--------------------|-----------|----------------------|---------------------------|
| **Desempeño (Performance)** | Comportamiento temporal | Alta (1) | Un instructor carga el dashboard con las analíticas de 100 alumnos en hora pico, y el sistema responde en menos de 2 segundos. | Uso de Caché Redis (ADR-004) para consultas pesadas y *Stored Procedures* (ADR-006) para cálculos en DB. |
| **Seguridad (Security)** | Confidencialidad | Alta (2) | Un atacante intenta acceder a la API de reportes sin credenciales válidas; el sistema deniega el acceso inmediatamente. | Implementación de JWT (ADR-002) y filtros de Spring Security en todos los endpoints protegidos. |
| **Fiabilidad (Reliability)** | Tolerancia a fallos | Media (3) | El contenedor de la base de datos PostgreSQL se reinicia inesperadamente; la aplicación web maneja el error y no expone el stack trace al usuario. | Orquestación mediante Docker Compose (ADR-005) con políticas `restart: always` y manejadores `@ControllerAdvice`. |
| **Mantenibilidad** | Modificabilidad | Media (4) | El equipo decide cambiar el proveedor de IA Externa; el impacto se limita a una sola clase o interfaz en el backend. | Uso de Patrón Adapter / Facade en los *Services* de Spring Boot para aislar la comunicación con IA. |
| **Usabilidad (Usability)** | Operabilidad | Alta (5) | Un alumno accede al simulador por primera vez y completa una sesión de prueba sin necesidad de un manual. | Interfaces SPA dinámicas construidas en Angular (ADR-001) y validadas mediante pruebas SUS (Bloque F). |
